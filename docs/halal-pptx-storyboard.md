# PPTX Generation Brief: Halal Vertical Attack Plan

Generate a 10-slide consultant-grade PowerPoint presentation (16:9, widescreen). The tone is professional strategy advisory -- think McKinsey or BCG, not startup pitch deck. Dense with detail, but visually structured so a senior stakeholder can scan it.

---

## Brand System

Use these exact colors and typography throughout:

### Colors
- **Gold** `#B8860B` -- primary accent, top-border bars, key highlights
- **Amber** `#D4A843` -- secondary accent, Phase 2 badges, supporting highlights
- **Ivory** `#F5F0E8` -- slide background (light theme)
- **Royal** `#1A2744` -- headings, primary text, dark-background closing slide
- **Cobalt** `#2C3E6B` -- body text, Phase 1 badges, secondary headings
- **Ivory Dark** `#E8E0D0` -- borders, dividers, table lines
- **White** `#FFFFFF` -- card/tile/table cell backgrounds
- **Muted** `#6B6155` -- captions, descriptions, supporting text
- **Rose** `#8B2E3B` -- warnings, "Never" badge, blockers

### Typography
- **Headings**: Georgia (serif), bold or regular weight
- **Body**: Arial or system sans-serif
- **Labels/Badges/Numbers**: Monospace where possible (Courier New), uppercase, wide letter-spacing

### Design Rules
- Every slide gets a thin Gold `#B8860B` horizontal bar across the full top edge (4-6pt tall)
- Section numbers (01, 02, 03...) appear in Gold monospace above each section title
- Cards and tiles use White backgrounds with Ivory Dark borders and a colored left-border or top-border accent (3pt)
- Tables use Royal `#1A2744` header row background with White text, alternating subtle row tinting
- The closing slide uses Royal `#1A2744` as full-slide background with Ivory text
- Generous whitespace. Do not crowd slides. Split content across multiple slides rather than shrinking fonts below 8pt.

## General Quality Notes

- This is not a pitch deck. It is an internal strategy document. The density of a McKinsey exhibit is the target -- every slide should have enough detail that someone reading it without a presenter understands the full argument.
- Do not add stock images, icons, or decorative illustrations. The visual system is typography, color accents, and structured layouts only.
- Tables should be tight and readable at 8pt body text. Bold stakeholder/capability names in the leftmost column.
- Badge labels are always uppercase, monospace, letter-spaced, small (7-8pt). They communicate category, not decoration.
- The 5-step execution flow on Slide 5 should visually read left-to-right as a sequence. Use connecting arrows or chevrons if the tool supports it.
- If the tool supports slide masters or layouts, set the Ivory `#F5F0E8` background and Gold top bar as the default master so it appears on every slide automatically.
