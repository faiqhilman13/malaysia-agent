Malaysia Agent Ops Architecture

Execution middleware for AI agents on Malaysian business rails — halal dossier pre-checks, e-invoicing, payments, and compliance

Agent Entry Points

  • • CLI — manage.py action <action> --json
  • • HTTP API — ThreadingHTTPServer :8080 /v1/*
  • • MCP Server — stdio JSON-RPC for Claude/Cursor
  • • Repo-local Skill — SKILL.md agent contract
  • • Static Frontend — Halal Ops Workbench

Provider Adapters

  • • MyInvois (LHDN) — auth, TIN, submit, status, cancel
  • • CIDB N3C — experimental adapter surface, outside current core scope
  • • PayNet / DuitNow — planned payment settlement
  • • MyDigital ID — planned delegated authority
  • • DagangNet / NSW — planned trade logistics

Design Principles

  • • Python stdlib only — zero external dependencies
  • • SQLite for durable state — no external DB
  • • Sandbox / Live dual mode — deterministic testing
  • • Agent-first responses — status + next_action + data
  • • 45 action contracts across 9 domains
